READING MATERIALS
Place approved PDFs/documents in the reading-materials folder. Add links to those files on resources.html. The current page is a public resource library layout; it does not include student login or private uploads.

FORMS
The application, enquiry and certificate-verification request forms use Netlify Forms. Deploy this folder to Netlify and enable form notifications to the IPSM email address. No payment gateway or certificate database is included. Those require a separately configured backend and authorised institutional records.

DEPLOY
1. Create a free Netlify account.
2. Deploy the site folder (or drag-and-drop the unzipped folder).
3. In Netlify, open Forms and confirm the three forms are detected.
4. Add an email notification for each form to ipmz37175@gmail.com.
5. Set the production domain/name.

IPSM is not represented as the operator of NeST, a PPRA-approved NeST training provider, or an organisation accredited by UNCITRAL, OECD, the World Bank or ISO. APPLICANT DOCUMENT UPLOAD AND PRIVACY
- A new documents.html page explains the supporting documents applicants should prepare: academic certificates/transcripts, national ID, passport and (where requested) birth certificate.
- The file fields are intentionally disabled. No documents are uploaded or stored by this page yet.
- Identity documents and academic records contain personal information. Do not activate ordinary Netlify file uploads for these records without configuring the additional security protection Netlify recommends for personally identifiable information (PII), reviewing privacy obligations, limiting staff access, setting a retention/deletion schedule and publishing an applicant privacy notice.
- Netlify Forms documentation states that one file is supported per upload field, the total form request limit is 8 MB and uploads time out after 30 seconds. Netlify recommends the Very Good Security integration for forms that collect file uploads containing PII. Check current plan usage and charges before deployment.
- The application form remains a separate basic admissions enquiry/application form. The document upload portal must be connected to an approved secure storage service before the disabled fields and submit action are enabled.
- The application form JavaScript no longer displays a simulated success message; it submits natively to Netlify Forms, subject to enabling form detection and configuring notifications in the Netlify dashboard.
